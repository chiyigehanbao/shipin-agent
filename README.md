# 幻帧工坊 · VisionForge Studio

**把剧本、角色、分镜与成片组织进同一个 AI 创作工作台。**

幻帧工坊是一个面向 AI 视频制作的本地全栈应用。它以项目为单位管理创作素材，将文本扩写、角色与场景资产、分镜规划、模型提示词、配音与成片合成连接起来，并提供后台任务和模型服务的运行信息。

前端采用 React、Vite、Ant Design 与 Zustand，后端采用 FastAPI 与 SQLite。应用连接本机或自行配置的 LLM、ComfyUI、TTS 和音乐服务，模型权重与创作产物单独存放。

## 创作流程

1. **建立项目**：选择项目类型并输入故事或文本。
2. **剧本工坊**：扩写场景、润色表达，组织台词与情绪信息。
3. **资产生成**：从剧本整理角色、场景与道具，生成和选择候选资产。
4. **分镜故事板**：将场景拆成镜头，管理参考素材和模型提示词。
5. **成片合成**：围绕分镜、配音、字幕与背景音乐组织输出。

## 主要能力

### 剧本与资产

剧本扩写与电影感润色通过模型服务执行，角色、场景和道具按项目保存。角色选角支持多候选方案与明确选择，减少把未确认的候选直接传给下游。

项目还包含人物身份参考、裁切、参考资产与相关评估模块。参考控制的可用性和实际一致性效果取决于本机模型、工作流节点和输入素材。

### 分镜与提示词

分镜用于连接故事、人物与图像或视频任务。项目以视觉圣经和 Prompt IR 保存上游创作约束，再为具体模型编译提示词。

MiniMax H3 相关模块包含指南加载、格式编译、校验、编辑与锁定，以及来源变动后的过期处理。提示词可以检查通过，与模型服务成功生成图像或视频是两个独立步骤。

### 合成与音频

成片合成围绕分镜素材、台词配音与 FFmpeg 处理。TTS 提供 Edge/VoxCPM 等相关适配，BGM 可连接独立 ACE-Step 服务；视频任务还包含 ComfyUI 工作流调用模块。

不同生成服务需要单独安装和配置，并非只启动前后端就会自动具备全部生成能力。

### 创作经验与模板

项目包含提示词模板管理、案例知识库、检索和项目经验入库。案例检索需要可用的本地 Embedding 模型；存储实现包含 Chroma 与 JSON 向量回退路径。

### 任务与监控

后台任务统一记录状态，界面可查看进度、错误与运行队列。相关控制包含重试、暂停、恢复与取消；监控模块还读取主机与 GPU 信息。

## 工程特点

- **素材与元数据分离**：SQLite 记录项目、资产、分镜、任务和模板，图片、音频和视频落在模型资源目录。
- **生成能力分层**：页面、API、任务处理器、模型客户端与具体工作流分别组织。
- **长任务后台执行**：页面切换与任务状态分开管理，便于恢复观察和处理失败。
- **创作约束可追踪**：视觉规范、人物选择、编译产物与版本状态参与下游任务校验。
- **测试数据隔离**：测试入口在导入应用前设置独立数据库与模型目录，避免使用现有创作库。

## 本地启动

需要 Python、Node.js/npm。生成能力另外需要配置相关服务；合成需要 FFmpeg。

在 `backend/` 创建并激活虚拟环境，然后执行：

```sh
pip install -r requirements.txt
# 将 .env.example 复制为 .env，并按本机配置路径与服务地址
python -m uvicorn app.main:app --reload --host 127.0.0.1 --port 8010
```

另开终端启动前端：

```sh
cd frontend
npm ci
npm run dev
```

- 前端：http://localhost:3000
- 后端 API：http://localhost:8010/api/docs
- 模型资源根目录：通过 `MODELHUB_ROOT` 配置。

前端代理默认连接 8010。ComfyUI 是独立服务，需与应用后端使用不同端口。

## 配置与检查

`backend/.env.example` 提供模型目录、ComfyUI、Ollama、云端 LLM、SQLite、FFmpeg 和 VoxCPM 的配置入口。云端密钥使用自己的本地环境配置，仓库不带现有模型权重或项目数据库。

```sh
cd backend
pip install -r requirements-dev.txt
python -m pytest tests
```

前端构建在 `frontend/` 执行 `npm run build`。真实出图、视频、配音和合成分别依赖对应服务，需要在完成本地配置后单独验证。

```text
  pages/workbench/   项目、剧本、资产、分镜与成片页面

  pages/monitor/     任务与运行信息
  store/             前端项目状态
backend/app/
  api/               项目与各创作模块接口
  services/          生成、检索、任务、合成与模型适配
  prompt_packs/      模型提示词指南资源
  db/                数据访问与迁移
  core/              路径与环境配置
backend/tests/       任务、资产、提示词与接口检查
```

## 项目范围

仓库整理的是当前应用源码、必要提示词资源和测试，未包含下载的第三方参考项目、CosyVoice/VoxCPM 完整源码、权重、创作数据库或生成产物。相关模型与工具属于各自独立项目，应单独安装并遵循其许可。
