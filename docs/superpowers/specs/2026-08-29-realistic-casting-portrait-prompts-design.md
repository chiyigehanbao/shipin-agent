# 真实演员试镜照提示词改造设计

日期：2026-08-29

## 背景与问题

当前角色 AI 选角提示词把多个商业美颜信号叠加在一起：`polished commercial`、`pale skin`、`harmonious features`、`soft frontal studio light` 和 `85mm portrait`。实际生成的四张“苏晚”候选均出现相似问题：面部高光像自发光，皮肤油润且被磨平，五官比例趋向通用网红脸，缺少真实演员试镜照应有的皮肤微结构、轻微不对称与摄影层次。

Flux 工作流当前使用 `CFG=1.0`。因此 `plastic skin`、`beauty filter` 等负面提示词不能承担核心纠偏责任；重要约束必须以正向、可执行的摄影语言写进主提示词。

## 目标

- 角色候选图接近未经修饰的真实演员试镜照，而不是商业美颜头像。
- 保留精致、适合短剧选角的演员气质，但不依赖磨皮、油光、夸张妆容或网红脸比例。
- 四个候选在脸部几何和稳定气质上明显不同，摄影条件保持一致。
- 当前“苏晚”可以用新模板重新生成四版，旧图和旧候选记录不自动删除。
- 不改变分镜提示词、身份参考管线或 MiniMax H3 视频流程。

## 非目标

- 本阶段不修改 Flux 模型、CFG、采样器或工作流节点。
- 不增加图像自动评分、视觉模型质检或自动重试。
- 不把剧情状态、情绪表演、天气、受伤或服装损坏写进身份锚点。
- 不追求证件照式的无影平光，也不追求刻意粗糙、脏污或过度锐化的皮肤。

## 方案决策

采用提示词层的单变量改造。先修正选角导演指令、回退模板和输出校验，再通过同一 Flux 工作流重新生成，以便明确判断提示词改造的效果。若真实 A/B 仍存在稳定油光，再单独设计工作流参数校准，不与本阶段混合。

## 提示词结构

每个候选的英文提示词按以下固定顺序组织：

1. **用途与媒介**：`unretouched actor casting photograph`，明确这是演员试镜参考，不是美容广告或社交媒体头像。
2. **稳定身份**：年龄印象、脸型、颧骨、下颌、眉眼、鼻唇比例、稳定发型和体型。
3. **真实皮肤响应**：`matte skin response`、`visible natural pores and fine facial texture`、`subtle uneven skin tone`、`minor facial asymmetry`。这些词描述正常人脸，不使用 `flawless`、`perfect` 或 `pale skin`。
4. **摄影条件**：胸像、视平线、50mm、f/8、相机距离固定、双眼和面部主要平面同时清晰、45 度侧前方大面积漫射主光、柔和高光过渡但不产生面部辉光、中性灰背景。
5. **一致性约束**：四版使用相同机位、构图、曝光、背景、妆发强度和服装中性度，仅比较脸部几何与稳定气质。

核心正向摄影片段为：

> unretouched actor casting photograph, matte skin response, visible natural pores and fine facial texture, subtle uneven skin tone, minor facial asymmetry, soft highlight roll-off without facial glow, minimal colorless grooming, chest-up eye-level framing, 50mm lens at f/8, both eyes and facial planes equally resolved, large diffused key light placed 45 degrees off camera, neutral gray background, identical camera distance, exposure and comparison framing

负面提示词继续作为次级保护，覆盖：蜡皮、湿亮皮肤、油性高光、磨皮、美颜滤镜、HDR 局部对比、锐化光晕、过度降噪、玻璃眼、娃娃脸、网红脸比例、夸张妆容、浅景深导致单眼失焦、文字和水印。任何关键要求不能只存在于负面提示词中。

## 选角候选规则

- LLM 必须返回四个候选，且每个 `identity_anchor` 仅包含永久性面部几何和稳定年龄印象。
- 四版差异至少覆盖脸型、眉眼、鼻型、唇形或骨相中的两个维度；不能只改变发型、妆容或表情。
- `prompt_en` 必须包含新的用途锚点和真实皮肤摄影片段。
- 出现 `polished`、`pale skin`、`flawless`、`perfect skin`、`beauty lighting`、`soft frontal studio light` 或剧情临时状态时，LLM 结果判定无效，整组回退到确定性模板。
- 回退模板保留四种不同骨相方向，但不再使用 `harmonious distinctive features` 等容易把脸平均化的表达。

## 系统改动

### 选角服务

修改 `backend/app/services/casting.py`：

- 更新 LLM system message，要求真实演员试镜摄影和统一摄影条件。
- 重写四个确定性回退提示词。
- 将输出校验从检查 `polished commercial short-drama actor` 改为检查真实试镜用途锚点、皮肤响应片段和禁用美颜词。
- 保持 `CastingConcept` 数据结构与 API 返回格式不变。

修改 `backend/app/api/assets.py`：

- 再次选角时创建新的候选组和四条新记录，避免覆盖历史图片。
- 选定候选时清理同名角色其他选角组的 `selected` 状态，但不删除历史记录。
- 更新选角负面提示词作为次级保护，不依赖它表达关键写实要求。

### 当前项目数据

代码上线后，对项目 `proj_6d3b085b06` 的“苏晚”再次调用现有 AI 选角接口。若来源已经属于一个选角组，再次选角必须创建新的候选组和四条新资产记录，不得复用或覆盖旧组的资产 ID 与图片文件。首次从普通角色资产发起选角时仍可复用来源资产作为候选 1，保持现有数据兼容。

同名角色可以保留多个历史选角组，前端继续通过现有同名版本列表展示。用户选定新组中的一版时，后端把该同名角色其他选角组的候选一并标记为 `rejected`，确保全项目只有一个当前 `selected` 身份；历史图片和记录仍保留可查看。

### 前端

本阶段不修改前端交互。现有 `AI 选角 · 生成 4 版`、候选 1–4 切换和“选定此版长相与气质”流程继续复用。

## 错误处理与兼容性

- LLM 输出缺字段、不是四版、候选不够区分、含禁用词或含剧情临时状态时，使用确定性回退模板。
- API、数据库字段和身份锁结构不变，因此旧候选和已选角色保持可读。
- 再次选角期间保留旧的已选身份，直到用户明确选定新候选；生成失败不会破坏原有可用身份。
- 新校验只应用于新一次选角生成，不回写或迁移历史资产提示词。
- 若 ComfyUI 不可用，沿用现有队列错误和重试行为。

## 测试设计

新增或更新自动化测试，先验证失败再实现：

- 四个有效 LLM 候选必须包含真实试镜用途锚点和正向皮肤响应约束。
- 含 `polished`、`pale skin`、`flawless`、`beauty lighting` 或 `soft frontal studio light` 的结果必须触发回退。
- 回退提示词不得包含美颜触发词，且必须包含哑光皮肤、自然毛孔、轻微肤色差异、轻微不对称、无面部辉光、50mm f/8 和侧前方漫射光。
- 四个回退身份锚点保持唯一，不含雨、水、血、泥、疲惫、汗或受伤等临时状态。
- 选角 API 仍生成且入队四个候选，不改变候选选择流程。
- 从历史候选再次选角会得到新的候选组和四个新资产 ID，旧组状态与图片不被覆盖。
- 选定新组候选后，同名角色所有旧组不再保留第二个 `selected` 状态。
- 完整后端测试集保持通过。

## 真实效果验收

用同一“苏晚”角色简介和同一 Flux 工作流生成新四版，人工检查：

- 面颊、额头和鼻部没有大面积湿亮或自发光高光。
- 皮肤可见自然微结构与轻微色差，但没有过度锐化、脏皮或夸张毛孔。
- 双眼清晰，面部不同平面解析均衡，没有单眼虚焦和锐化光环。
- 五官存在可信的轻微不对称，四版不是同一张网红脸的细微变体。
- 妆容、曝光、背景和构图足够一致，可以专注比较长相与气质。

如果四版仍一致出现油光，记录结果并进入独立的 Flux 工作流校准设计；不在本阶段临时叠加 CFG 或采样改动。

## 发布与回滚

发布包含选角服务、选角 API 及其测试。回滚时恢复对应 Python 文件即可，数据库和历史资产无需迁移。新生成的图片作为普通候选保留，用户可以继续查看或重新选角。
